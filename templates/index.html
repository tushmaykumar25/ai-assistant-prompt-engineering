NovaMind AI — User Guide

How to use this Flask-based AI Assistant and how prompt design shapes AI responses.

How to Run the App
🚀

Starting the Flask Server

Open a terminal in the project folder and run:

pip install flask requests
python app.py

Then open your browser at http://127.0.0.1:5000

Flask Routes (Backend)
🌐

GET /

Serves the main HTML page (this interface) using render_template('index.html').

🔑

POST /set-key

Saves the Gemini API key to the Flask session on the server. The key never leaves the backend.

🤖

POST /generate

Receives function + style + input, builds the prompt in Python, calls Gemini API, and returns the response as JSON.

👍

POST /feedback

Appends feedback (function, style, query, helpful) as a JSON line to feedback_log.txt.

📊

GET /feedback-log

Reads and returns all entries from feedback_log.txt as JSON for display in the Feedback Log tab.

Quick Start Steps
🔑

Step 1 — API Key

Get a free Gemini key at aistudio.google.com. Paste it in the banner and click Save Key. Flask stores it in your session.

🎛️

Step 2 — Pick Function

Choose one of the 4 functions: Q&A, Summarizer, Creative Writer, or Smart Advisor.

🎨

Step 3 — Pick Style

Choose Simple, Detailed, or Expert. The preview shows the exact prompt template Flask will send to Gemini.

✍️

Step 4 — Generate

Type your input and click Generate. Your browser sends a POST to Flask, Flask calls Gemini, and returns the response.

👍

Step 5 — Feedback

Rate the response. Flask saves it to feedback_log.txt. View all entries in the Feedback Log tab.
